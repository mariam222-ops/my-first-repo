# How to Create and Upload a Repository to GitHub

## Steps to Follow:
1. **Initialize Local Repo**: Use `git init` in your project folder.
2. **Create Files**: Add your project files (e.g., index.html, README.md).
3. **Stage Changes**: Run `git add .` to prepare files for saving.
4. **Commit**: Save your work with `git commit -m "Your descriptive message"`.
5. **Connect to GitHub**: Create a new repo on GitHub and link it using:
   `git remote add origin <repo_url>`
6. **Push**: Upload your files using `git push -u origin main`.
